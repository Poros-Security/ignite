# Contributing

## 1. Clone repository
```bash
git clone https://github.com/poros-security/lab-inkubasi.git
cd lab-inkubasi
```

## 2. Buat branch baru
```bash
git checkout -b <nama-kamu>/<nama-fitur>
```

## 3. Commit perubahan
```bash
git commit -m 'Add some <nama-fitur>'
```

## 4. Push ke branch
```bash
git push origin <nama-kamu>/<nama-fitur>
```
